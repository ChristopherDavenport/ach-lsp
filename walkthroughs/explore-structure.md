# Explore File Structure

The **ACH Explorer** panel appears in the Explorer sidebar when an ACH file is open.

It displays your file as a tree:

- **File Header** — routing numbers, creation date
- **Batches** — company name, SEC code, service class
  - **Entries** — individual name, amount, routing/account
    - **Addenda** — additional payment info
- **File Control** — totals and counts

Click any item to jump to that record in the editor.
