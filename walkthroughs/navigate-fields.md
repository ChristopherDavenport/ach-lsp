# Navigate Between Fields

ACH records are fixed-width — fields are defined by exact column positions, not delimiters.

## Field Navigation

| Action | Windows/Linux | macOS |
|--------|--------------|-------|
| Next field | `Ctrl+Right` | `Alt+Right` |
| Previous field | `Ctrl+Left` | `Alt+Left` |
| Select next field | `Ctrl+Shift+Right` | `Alt+Shift+Right` |
| Select previous field | `Ctrl+Shift+Left` | `Alt+Shift+Left` |

## Section Navigation

| Action | Windows/Linux | macOS |
|--------|--------------|-------|
| Next section | `Ctrl+Down` | `Alt+Down` |
| Previous section | `Ctrl+Up` | `Alt+Up` |

## Hover for Details

Hover over any field to see its **name**, **description**, **column range**, and **current value**.

## Context Menu

Right-click in the editor to **Select Field** or **Copy Field Value**.
