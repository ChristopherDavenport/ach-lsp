# Open the Preview Panel

The **ACH Preview** shows a structured, human-readable view of your file.

## Features

- **Field labels** — every field is labeled with its name and value
- **Search** — find entries by name, amount, or routing number
- **Diagnostics** — validation errors are highlighted inline
- **Diff view** — compare changes as you edit
- **Edit support** — make changes in the preview and they sync back to the editor

## Opening

- Click the **preview icon** in the editor title bar
- Use `Ctrl+Shift+V` (Windows/Linux) or `Cmd+Shift+V` (macOS)
- Run **ACH: Open Preview** from the Command Palette
